College Project Demonstration

Tourist Attraction Information Service Portal

This web application is developed as a college project for practical evaluation. It demonstrates client-server web programming, database-driven content delivery, REST API development, and responsive user interface design.

Department: Computer Science & Engineering (CSE) | Academic Year: 2026
Status: Completed & Live
Server: Node.js Express
DB: SQLite (19 Attractions)

1. Purpose of the Portal

Tourists often struggle to find accurate, verified, and centralized information on regional attractions, including timings, ticket prices, and facilities.

The purpose of this portal is to provide a user-friendly, responsive digital guide highlighting tourist attractions in Telangana (Charminar, Golconda, Ramappa Temple, Ramoji Film City, Nagarjuna Sagar) and famous national destinations across India.

2. Core Objectives

  • Build a functional full-stack web application with Node.js and Express.js.
  • Store destinations and contact inquiries persistently using an SQLite database.
  • Provide search, multi-category filtering, and state-wise filtering without full-page reloads.
  • Allow tourists to save favorites in browser local storage.
  • Provide direct Google Maps location coordinates for travel planning.

3. Portal Features

  • Dynamic Catalog: 19 sample destinations loaded through backend REST APIs.
  • Live Search & Filter: Real-time filtering by category, state, and keywords.
  • Rich Attraction Details: Timings, entry fees, image galleries, and facility lists.
  • Favorites Wishlist: Saves favorite places to guest local storage.
  • Contact Inquiry Form: Validates user input and saves to SQLite.
  • Admin Dashboard: Basic protected console to manage destination records.

4. Benefits for Tourists

  • Time Saving: View hours, entry fees, and nearby attractions in one screen.
  • Easy Navigation: Click-to-open Google Maps directions for any spot.
  • Responsible Guidelines: Learn essential travel, packing, and safety precautions.
  • No Compulsory Login: Tourists can bookmark attractions immediately.
  • Mobile Friendly: Works on desktop, tablets, and smartphones.

5. Technologies Used

Component Technology Purpose in Project
